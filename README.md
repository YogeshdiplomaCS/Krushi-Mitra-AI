# Krushi-Mitra-AI

An agriculture-focused Streamlit project for exploring crop recommendations, plant-health support, fertilizer guidance, and irrigation ideas. Verify each feature and its data/model source in the code before relying on its output for real farming decisions.

## Run locally

1. Install Python 3.10 or later.
2. Clone the repository and enter the project folder:

   ```bash
   git clone https://github.com/YogeshdiplomaCS/Krushi-Mitra-AI.git
   cd Krushi-Mitra-AI
   ```

3. Create and activate a virtual environment, then install dependencies:

   ```bash
   python -m venv .venv
   # Linux/macOS: source .venv/bin/activate
   # Windows PowerShell: .venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

4. Set any required service credentials in your local environment or local secrets configuration. Never commit real credentials. Check the app's configuration code for required setting names.
5. Run the app:

   ```bash
   streamlit run app.py
   ```

## Important

This project is for learning and experimentation; AI or model recommendations are not a substitute for local agricultural expertise. Document data sources, model limitations, tested environments, and screenshots as these are verified.
